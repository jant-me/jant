# Demo Canonical

`sites/demo-source/canonical/` stores the committed demo truth that drives
`demo-public`.

- `snapshot/` is the current identity-preserving canonical artifact generated by
  `mise run demo-source-export-canonical`.
- `site-export/` is a portability fixture generated by
  `mise run demo-source-export-canonical-site-export`, which hits the deployed
  `demo-source` Worker over HTTP (requires `JANT_API_TOKEN`). Use it to
  regression-test `jant site export/import` and to seed local Node runtimes
  without relying on snapshot restore.
- The old static `export/` directory is retired. Public demo rebuilds still use
  `jant site snapshot export/import`, not static site export/import.

Refresh the snapshot from the live `demo-source` Worker with:

```sh
mise run demo-source-export-canonical
```

Refresh the canonical site export directly from the deployed Worker with
(`JANT_API_TOKEN` must be set — mint one in demo-source Settings → API Tokens):

```sh
mise run demo-source-export-canonical-site-export
```
