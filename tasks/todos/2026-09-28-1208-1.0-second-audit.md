# 1.0 前第二轮审查：问题清单

2026-09-28 对 0.10.0（`3d25692b`）做的第二轮只读审查，覆盖 HTTP API 与 MCP、其余冻结面（命令行、配置、主题、Feed 与地址、
导出与 snapshot、模板、Docker）、安全与隐私、运维与发版、路线图。上一轮见 `2026-09-26-1749-1.0-freeze.md`。

标「待复核」的只有审查报告的代码阅读，没有复现，动手前先核实。其余要么有临时测试复现，要么对过代码。

## 已定的原则

- **1.0 之前不留兼容**：新设计更好就直接换，变化写进 Upgrade notes。不给改名的字段、变量留别名，不接受旧格式，
  不保留旧文件名。例外有两个，它们保护的东西已经在外面：读者保存的公开地址和 feed 地址；旧版本写出的导出和
  snapshot（发版夹具守着）。
- **请求宽容**：服务端忽略请求里不认识的字段和参数，不因此返回 400。1.0 之后字段改名时旧名保留为别名。

## 做法

- 每项单独提交，推 `main`。推 `main` 会经 `deploy-studio-prod` 部署托管服务和 owenyoung.com，demo.jant.me 每晚部署
  `main` 上最近一次 CI 通过的版本。
- 每项改动随手写 changeset（Upgrade notes）。Release PR 开着不合并；三条部署路径跑稳、Owen 确认后再合并发版。
- 顺序：S → D → A → C → L → T → F → Q → P（承诺文档最后统一改，前面的改动会影响它）→ R。
