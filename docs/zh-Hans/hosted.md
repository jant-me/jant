# 使用 Jant 托管

Jant 是开源的，可以自己部署。不习惯自己部署，也可以用 [jant.me](https://jant.me) 的托管服务：跑的是同一份开源代码，运维交给托管侧。

→ [前往 jant.me/signup 注册](https://jant.me/signup)（已有账号就[登录](https://jant.me/signin)）

## 价格与配额

只有一种套餐：

| 项目     | 包含        |
| -------- | ----------- |
| 价格     | $10.46 / 年 |
| 站点数   | 3 个        |
| 媒体存储 | 10 GB       |

按年结算。取消后站点运行到当前周期结束，然后进入 90 天保留窗口，期间数据可以恢复，之后永久删除。

首次付款后 14 天内可以退款，在 dashboard 里自助操作（计费 → 申请退款），每个套餐一次。退款立刻结束套餐：站点下线，进入同样的 90 天保留窗口，期间重新订阅可以恢复。

## 包含的服务

- **完整的 Jant 功能**：Threads、Collections、GitHub 同步、API/MCP、Hugo 导出，和自托管一致。
- **自定义域名与 HTTPS**：在 dashboard 里绑定自己的域名，证书自动签发与续期。
- **数据库与媒体存储**：由托管侧配置和运维。

## 开始使用

1. 在 [jant.me/signup](https://jant.me/signup) 注册账号。
2. 创建站点。新站点会拿到一个 `*.jant.blog` 子域名，立刻可用。
3. （可选）绑定自己的域名：dashboard → 选中站点 → **域名** → 添加域名，按提示在你的注册商处配置 DNS。

## 随时可以迁移

两种方式：

- **[Hugo 导出](export-and-import.md)**：把所有帖子、媒体和设置导出成标准 Hugo 站点目录，可以直接部署到任何 Hugo 主机。
- **[GitHub 同步](github-sync.md)**：站点持续把内容同步到你自己的 GitHub 仓库。仓库本身就是一个完整的 Hugo 站点，随时可以独立运行。

托管与自托管之间可以互相迁移，走同一套导入流程。

## 与自托管的差异

| 项目       | 托管         | 自托管                                                                    |
| ---------- | ------------ | ------------------------------------------------------------------------- |
| 配置成本   | 注册即用     | 按 [Cloudflare](deployment.md) 或 [Docker](deployment-docker.md) 文档配置 |
| 升级与运维 | 自动         | 自行执行                                                                  |
| 数据所在   | 托管运行环境 | 你自己的环境                                                              |
| 成本       | $10.46 / 年  | 通常在 Cloudflare 免费额度内                                              |

## 为什么是 $10.46

$10.46 是 Cloudflare 注册和续费一个 .com 域名一年的价格。我认为我们在使用一个长期的订阅服务时必须考虑它的长期成本，$10.46 在我看来是一个公平合理的价格。
