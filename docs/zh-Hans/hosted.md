# 使用 Jant 托管

[jant.me](https://jant.me) 提供 Jant 的托管服务。托管版与自托管版运行同一份开源代码，没有托管专属功能。服务器、数据库、媒体存储、升级和 HTTPS 证书由 Jant 负责。

## 价格

只有一种套餐，按年计费：

| 项目     | 包含                |
| -------- | ------------------- |
| 价格     | $10.46 / 年         |
| 博客数   | 3 个                |
| 媒体存储 | 10 GB，所有博客共用 |

## 开始使用

1. 在 [jant.me/signup](https://jant.me/signup) 注册账号。
2. 在控制台创建博客并完成付款。之后博客可以通过分配的 `*.jant.blog` 子域名访问。
3. （可选）绑定自己的域名：在控制台打开博客，在「自定义域名」里添加域名，按提示在 DNS 服务商添加记录，再点「我已添加，去验证」。证书自动签发和续期。每个博客可以绑定一个自定义域名。

## 取消、退款与删除

在「计费 → 在 Stripe 中管理」里取消订阅。取消后博客继续运行到当前计费周期结束，然后下线，数据保留 90 天：

- 保留期内续订套餐，博客恢复上线。
- 保留期内仍可以在博客页面导出内容。
- 期满后数据永久删除，删除前 30 天、7 天和 1 天会发邮件提醒。

首次付款后 14 天内，可以在「计费 → 申请退款」自助全额退款，每个账户限一次。退款后套餐立即结束，博客下线，同样保留 90 天。

在博客页面选择「删除博客」会立即永久删除，不经过保留期。

## 迁移

Jant 是开源的博客系统。你可以随时按 [Cloudflare](deployment.md) 或 [Docker](deployment-docker.md) 的文档自己运行 Jant，把托管博客迁过去；从自托管迁到托管也一样。迁移分两步：先用 `site export` 把博客导出为标准 Hugo 站点目录，包括帖子、媒体和站点设置，再用 `site import` 导入新站点。详见[导出与导入](export-and-import.md)。

导出的目录也可以直接部署到任何支持 Hugo 的主机。想一直保留一份副本，可以开启 [GitHub 同步](github-sync.md)：内容会持续同步到你自己的 GitHub 仓库，仓库本身就是一个完整的 Hugo 站点。

## 与自托管的区别

| 项目          | 托管                    | 自托管                                                                    |
| ------------- | ----------------------- | ------------------------------------------------------------------------- |
| 部署          | 注册后在控制台创建      | 按 [Cloudflare](deployment.md) 或 [Docker](deployment-docker.md) 文档部署 |
| 升级与运维    | Jant 负责               | 自己负责                                                                  |
| 数据存放      | Jant 管理的数据库和存储 | 你自己的数据库和存储                                                      |
| 费用          | $10.46 / 年             | Cloudflare 通常在免费额度内；Docker 取决于服务器费用                      |
| Jant Discover | 默认加入                | 默认不加入                                                                |

两种方式都可以在「设置 → 常规 → 站点可见性」里开关 Jant Discover。

## 为什么是 $10.46

$10.46 是 Cloudflare 注册或续费一个 .com 域名一年的价格。订阅服务一用就是很多年，要按多年的总成本来衡量，我认为这个价格是公平的。
