# 使用 Jant 托管

如果你不想处理部署、升级、备份这些事，可以直接使用官方在 [jant.me](https://jant.me) 提供的托管服务。它和自托管运行的是同一份开源代码。

→ [前往 jant.me/signup 注册](https://jant.me/signup)（已有账号:[登录](https://jant.me/signin)）

前 30 天免费试用，无需信用卡。

## 价格与配额

Jant 托管的定价很简单，只有一种套餐：

| 项目     | 包含        |
| -------- | ----------- |
| 价格     | $10.46 / 年 |
| 站点数   | 3 个        |
| 媒体存储 | 10 GB       |

需要更多存储空间? 发邮件至 [support@jant.me](mailto:support@jant.me)，我们会单独安排。

到期前添加付款方式，就会按 $10.46 / 年自动续费；不添加，站点会下线，进入和取消后一样的 90 天保留窗口。

按年结算。取消后站点继续运行至当前付费周期结束；周期结束后进入 90 天保留窗口，期间数据仍可恢复；90 天后永久删除。

数据始终可以通过 [Hugo 导出](export-and-import.md) 或 [GitHub 同步](github-sync.md) 持续保留在你自己的环境。

## 包含的服务

- **完整的 Jant 功能**：Threads、Collections、GitHub 同步、API/MCP、Hugo 导出等所有特性都可用，与自托管版本一致。
- **自动 HTTPS**：默认子域名和绑定的自定义域名都会自动签发与续期证书。
- **自定义域名**：在 dashboard 中绑定你自己的域名。
- **数据库与媒体存储**：由托管侧统一配置和运维，你看到的只是 dashboard 里的站点。

## 开始使用

1. 在 [jant.me/signup](https://jant.me/signup) 注册账号。
2. 创建站点。新站点会拿到一个 `*.jant.blog` 子域名，立刻可用。
3. （可选）绑定自己的域名：dashboard → 选中站点 → **域名** → 添加域名，按提示在你的注册商处配置 DNS。证书自动签发与续期。

## 内容随时可以带走

托管和自托管跑同一份开源代码：

- **[Hugo 导出](export-and-import.md)**：把所有帖子、媒体、设置一次性导出为标准 Hugo 站点目录，可立即跑在任何 Hugo 主机上。
- **[GitHub 同步](github-sync.md)**：让站点持续把内容同步到你自己的 GitHub 仓库。仓库本身就是一个完整的 Hugo 站点，相当于你始终持有一份最新、可独立运行的副本。

任何时候都可以从托管切换到自托管，反过来也行——通过同样的导入流程。

## 与自托管的差异

| 项目       | 托管         | 自托管                                                                    |
| ---------- | ------------ | ------------------------------------------------------------------------- |
| 配置成本   | 注册即用     | 按 [Cloudflare](deployment.md) 或 [Docker](deployment-docker.md) 文档配置 |
| 升级与运维 | 自动         | 自行执行                                                                  |
| 数据所在   | 托管运行环境 | 你自己的环境                                                              |
| 成本       | $10.46 / 年  | 通常在 Cloudflare 免费额度内                                              |

## 为什么是 $10.46

这正好是 Cloudflare 提供的 .com 域名注册和续费的价格。略高于免费，又足够正式：不会让开始变得摩擦力太大，但也不是完全没有成本。
