# 统计

Jant 会统计页面浏览量，在 **Settings → 统计** 查看：最近 7、30 或 90 天的每日浏览量，这段时间里被读得最多的十篇帖子，以及读者从哪些站点点过来。点列表里的帖子，可以看它自己的每日浏览量和来源。

存下来的只有这些计数。Jant 不记录任何读者信息，不写 cookie，也不往页面里加脚本。超过 90 天的计数会删除。没有累计总数，也不和上一段时间比较。

## 什么算一次浏览

读者的浏览器打开一个页面，算一次浏览：首页、帖子页、合集页、归档页、`/featured` 或 `/subscribe`。Feed、搜索，以及你登录状态下打开的页面都不算；爬虫、链接预览和预加载也不算。

一篇帖子的数字，是它自己的页面被打开的次数。在首页上读完的笔记，算首页的浏览，不算这篇笔记的。

## 来源

来源是读者点链接过来的那个站点，只保留域名。链接带 `utm_source` 或 `ref` 参数时按参数值归类，不看从哪里打开：`?utm_source=newsletter` 记作 `newsletter`，ChatGPT 回答里的链接都带 `utm_source=chatgpt.com`。**直接访问**指两者都没有的访问：手动输入地址、书签，或从应用、邮件、RSS 阅读器里点开的未带参数的链接。大多数应用不传来源，所以直接访问通常是最大的一项。**其他**是列出的十项之外的全部。

## 关闭

在统计页底部取消勾选 **启用页面浏览统计**。停止计数，同时删除全部计数。对应的设置项是 `STATS_ENABLED`，见[配置](configuration.md#settings-页面设置)。

## 上限

部署在 Cloudflare 上时，一天统计到 20,000 次浏览后停止，第二天恢复。`STATS_DAILY_LIMIT` 可以改这个数，`0` 表示不限制，Docker 部署默认不限制。见[配置](configuration.md#统计可选)。

统计数据不包含在[导出](export-and-import.md)里，也不随站点迁移。
