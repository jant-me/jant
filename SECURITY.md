# Security

## Reporting a vulnerability

Report it privately through GitHub: on this repository's **Security** tab, choose **Report a vulnerability**. Don't open a public issue or pull request for it.

Say what an attacker can do, on which deployment (Cloudflare, Docker, Node, or Hosted Jant), and how to reproduce it. The reply comes in the same report.

## Supported versions

Fixes go into the latest release only; see [Compatibility](docs/compatibility.md#upgrading). Upgrade to it to get them. Hosted Jant sites are upgraded by the service.
